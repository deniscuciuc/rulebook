# Rulebook.Abstractions

Contracts and definition models for Rulebook — rule expressions, decision contexts and results. Reference this to describe or accept decisions without pulling in the engine.

Part of [Rulebook](https://github.com/deniscuciuc/rulebook). See the [documentation](https://github.com/deniscuciuc/rulebook#readme) for usage.

```
dotnet add package Rulebook.Abstractions
```
