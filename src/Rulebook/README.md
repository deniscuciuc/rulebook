# Rulebook

Rules engine for .NET: a boolean expression DSL compiled to delegates, plus feature flags, segmentation and deterministic A/B bucketing on top of it.

Part of [Rulebook](https://github.com/deniscuciuc/rulebook). See the [documentation](https://github.com/deniscuciuc/rulebook#readme) for usage.

```
dotnet add package Rulebook
```
